# Responsive Web Task (Task 4)

This project demonstrates converting a desktop-only HTML page into a mobile-friendly website using CSS media queries.

## Features

- Responsive navigation menu (stacks vertically on mobile)
- Flexible sidebar and main content area
- Responsive images that scale within containers
- No horizontal scrolling on mobile devices
- Simple, modern layout

## Files

- `index.html`: Home page
- `about.html`: About/project info
- `style.css`: Styles and media queries
- `script.js`: Optional JavaScript for interactivity
- `README.md`: Project overview and instructions

## How to Run

1. Download all files to a directory.
2. Open `index.html` in your web browser.
3. To test responsiveness, open Chrome DevTools and toggle device mode (`Ctrl+Shift+M`).

## Explanation

- Media queries in `style.css` adjust layouts for screens below 768px wide.
- The sidebar and main area stack vertically on mobile.
- Navigation adapts for mobile devices.
- Images auto-resize for flexible display.
